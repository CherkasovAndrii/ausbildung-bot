# Ausbildung-Bot

Telegram-бот, который ищет вакансии Ausbildung в Jobsuche API Bundesagentur für Arbeit,
присылает новые и отсеивает те, где требуют немецкий выше твоего уровня.

## Что умеет

- **Настройки прямо в боте** (`/settings`): профессии, федеральные земли, города с радиусом,
  отрасли работодателя, слова-исключения, дата начала, Duales Studium.
- **Список с листанием** (`/list`): по 5 вакансий на страницу, кнопки ◀️ ▶️.
  Над списком — кнопки твоих городов («только в городе» или «в радиусе»), сортировка
  (лучшие / ближе / новые) и экран «🗺 По городам» со счётчиками вакансий по местам.
  Новые вакансии приходят одним сообщением с таким же списком.
- **Рекомендации по требованиям**: бот загружает описание каждой подходящей вакансии и ищет
  требования к немецкому — уровень (B2, C1…), «Muttersprache», «verhandlungssicher»,
  «sehr gute / fließende Deutschkenntnisse». Вакансии с уровнем выше твоего скрываются,
  остальные сортируются: сначала те, где явно подходит твой уровень или предлагают Sprachkurs.

## Доступ

Бот личный: пользоваться им могут только люди из whitelist (по Telegram ID).

- **Владелец** задаётся переменной `OWNER_ID`. Если её нет, владельцем становится единственный
  подписчик, а если подписчиков нет — тот, кто отправит боту `/claim <код>` (код пишется в лог
  при запуске).
- **Добавить человека:** `/invite` создаёт одноразовую ссылку на 24 часа — человек открывает её,
  жмёт «Start» и получает доступ. Или `/allow <ID>`.
- **Незнакомец** видит «нет доступа» и свой ID, а владельцу приходит запрос с кнопками
  «Пустить / Отклонить».
- `/users` — список доступа с кнопками удаления, `/deny <ID>` — убрать по ID.
- Бот отвечает только в личных чатах.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | подписка |
| `/list` | подходящие вакансии списком |
| `/settings` | настройки поиска |
| `/check` | проверить новые вакансии сейчас |
| `/stats` | статистика: сколько скрыто из-за немецкого, топ городов и фирм |
| `/stop` | отписаться |
| `/users`, `/invite`, `/allow`, `/deny` | управление доступом (только владелец) |

## Как это устроено

| Файл | Что внутри |
|---|---|
| `bot.py` | Telegram-интерфейс, расписание проверок, уведомления |
| `api.py` | запросы к Jobsuche API (поиск, описания вакансий) и геокодер городов |
| `matching.py` | фильтры, разбор требований к немецкому, оценка вакансий |
| `db.py` | SQLite: вакансии, подписчики и их настройки |
| `tests/` | тесты разбора требований и фильтров (`pytest`) |

- Каждые `CHECK_INTERVAL_HOURS` часов бот загружает вакансии по всем профессиям подписчиков
  по всей Германии (`angebotsart=4` — Ausbildung и Duales Studium). Фильтры по землям,
  городам и прочему применяются локально.
- Описания вакансий загружаются фоном партиями по `ENRICH_BATCH` каждые `ENRICH_INTERVAL_MIN`
  минут, сначала для новых вакансий.
- Города переводятся в координаты через OpenStreetMap Nominatim, расстояние считается по
  координатам вакансии.
- История хранится в `jobs.db`: когда вакансия появилась и когда пропала.

## Запуск локально

Нужен Python 3.10+.

```
pip install -r requirements.txt
cp .env.example .env   # впиши BOT_TOKEN от @BotFather
python bot.py
```

Тесты:

```
pip install -r requirements-dev.txt
pytest
```

## Деплой на Railway

Проект берёт код из этого репозитория и пересобирается при каждом push в `main`.

- Переменные (`BOT_TOKEN` и другие из `.env.example`) задаются в Railway: сервис → **Variables**.
  Фильтры поиска настраиваются в самом боте, Railway для этого не нужен.
- База `jobs.db` лежит на Volume с путём `/data`, поэтому история не пропадает при редеплое.
- Логи: сервис → **Deployments** → **View logs**.
